### `brush-solid`

Synthesize a crisp constant-width hokusai brush. No scatter / no jitter — dabs are stacked densely so the stroke reads as a solid line.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `aa` | number (0…1) \| `$param` \| `@node` | no | — |
| `color` | color \| `$param` \| `@node` | yes | sRGB hex color, `$param` reference, or `@node` scalar port. |
| `dabs-per-radius` | number (0.5…∞) \| `$param` \| `@node` | no | Dab density along the stroke. Higher = smoother but slower. Default 4. |
| `hardness` | number (0…1) \| `$param` \| `@node` | no | — |
| `width-px` | number (0.4…∞) \| `$param` \| `@node` | yes | Stroke width in canvas pixels. |
