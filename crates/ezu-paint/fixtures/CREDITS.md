# Test fixtures

`watercolor_glazing.myb` is a MyPaint brush by David Revoy (deevad) from
[`mypaint/mypaint-brushes`](https://github.com/mypaint/mypaint-brushes),
released under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
It backs the stroke unit test and the paint benchmark, which need a realistic
brush to parse and render.
