# Test glyph range

`0-255.pbf` is the Basic Latin glyph range of **Klokantech Noto Sans
Regular** (Noto Sans patched by Klokan Technologies, licensed under the
SIL Open Font License 1.1 — see `OFL.txt` alongside), fetched verbatim
from the [openmaptiles/fonts] open glyph package
(`gh-pages` branch, `Klokantech Noto Sans Regular/0-255.pbf`).

It is a real fontnik-produced MapLibre glyph PBF — SDF bitmaps at the
24 px em with a 3 px border — used only by this crate's `text` feature
tests to exercise the SDF backend against server-shaped data.

[openmaptiles/fonts]: https://github.com/openmaptiles/fonts
