## Usage in the example styles

- `watercolor_glazing` — soft, low-opacity glaze. The `watercolor` style uses
  it for road strokes so many overlapping dabs build up colour gradually.
- `2B_pencil` — soft, dark graphite. The `pencil-sketch` style uses it for
  strong strokes (major roads, land boundaries).
- `4H_pencil` — hard, light graphite. The `pencil-sketch` style uses it for
  fainter strokes (minor roads).
